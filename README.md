# Суверенный Мессенджер (Sovereign Messenger)

Защищенный E2EE мессенджер с автоматическим защищенным туннелем для работы с ПК на весь мир.

---

## Как это устроено:

1. **Сервер на вашем ПК:**
   - Когда вы запускаете `1_start_server.bat` (или он уже работает в фоне), сервер поднимает локальный релей и **автоматически открывает защищенный интернет-туннель** (через Cloudflare).
   - Сервер выводит публичный адрес вида:
     `wss://fallen-operational-ext-pentium.trycloudflare.com`
   - **Этот адрес доступен из любой точки планеты:** через мобильный 4G/LTE, через любой домашний Wi-Fi и через любые VPN. Никаких настроек роутера и проброса портов!

2. **На компьютере:**
   - Запустите `CIPHER.exe` (или откройте `http://127.0.0.1:8080`).
   - Нажмите кнопку **`📱 Телефон`** вверху — откроется QR-код и ссылка на ваш сервер для быстрого подключения смартфона.

3. **На смартфоне Android:**
   - Установите файл **`SovereignMessenger.apk`**.
   - Нажмите вверху на красную плашку статуса (или внизу на адрес сервера).
   - Вставьте публичный адрес вашего сервера (например: `wss://fallen-operational-ext-pentium.trycloudflare.com`).
   - Плашка сразу загорится зеленым: **`🟢 В сети`**!
   - Всё! Вы можете обмениваться зашифрованными сообщениями между ПК и телефоном.
